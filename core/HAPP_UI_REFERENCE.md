# Android UI reference

The visual reference is the official [Happ Android 4.4.1 release](https://github.com/Happ-proxy/happ-android/releases/tag/4.4.1), asset `Happ.apk`. Its SHA-256 is `31457b085e9df2cfef846e28fbf39c6040baa4a1fee8328f085adeb9176ad9405`.

I decoded the APK's resources with Apktool 3.0.3 and inspected `res/layout/activity_main.xml`, `activity_settings.xml`, `activity_subscription_settings.xml`, `item_subscription.xml`, `item_server.xml`, and the light/dark app themes. The home layout puts settings and add actions in the top bar, a roughly 217 dp power control near the upper center, subscription and server rows below it, and clipboard and QR import actions at the bottom. Its light theme uses a pale neutral background with purple accents, including `#7c71ff`; the dark theme uses a deep indigo background around `#211f53`.

The Android app patch follows this hierarchy across its connection, profile, server, import and settings screens. The home view uses a responsive power control up to 210 dp with a code-drawn gradient ring, compact actions above the subscription rows, and fixed clipboard/QR actions at the bottom. The add control opens a menu under the top-right button. Secondary screens use toolbar back navigation instead of a persistent bottom bar. Server groups default to a single-column list with compact rows and a selected indicator. Settings use grouped text rows, thin dividers and chevrons. The color scheme is blue/cyan over pale blue or navy surfaces; buttons are rounded rectangles, and the bundled JetBrains Mono font replaces the Happ font. The launcher and About icons come from this repository's original Clash Mi source. The original Happ code, images, and APK are not part of this repository.

This is a source-level reconstruction of Happ's layout language, not a pixel-perfect clone. The two apps use different UI frameworks and expose different configuration features. In particular, the Mihomo-based app keeps its own proxy-group and configuration editors; Happ's Xray-specific fragmentation and noise settings have no matching controls here.
